# OASIS Fragrance Showroom Website

نسخة جديدة مبنية كمعرض تعريفي فاخر وليست متجرًا إلكترونيًا.

## Features
- Arabic / English toggle with RTL/LTR support.
- Luxury responsive design for desktop and mobile.
- Hero section using the provided OASIS showroom imagery.
- Expanded perfume-house directory with search and regional/category filters.
- Clicking a brand opens a WhatsApp availability enquiry.
- Gallery using the supplied OASIS visuals.
- Founder / success-story section for Saddam Fathi Mahmoud Kahla, founded in 2021.
- Fragrance consultation form that prepares a WhatsApp message.
- Official contact data, phone, email and location link.
- No e-commerce cart, prices, checkout or online payments.

## Run locally
Open `index.html` in a modern browser. For best results, run a small local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Free hosting options
The site is static and can be deployed as-is to Cloudflare Pages, GitHub Pages or Netlify.

## Content note
The brand directory is a discovery/reference directory. Brand listing does not claim permanent inventory or official affiliation. Actual availability is confirmed directly with OASIS.
